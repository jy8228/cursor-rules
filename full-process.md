#Rule : Full product development process

## Goal 

To define full product development steps 


## Process

1. Write **Product Draft** - Define what the product is about. Target users, Problem/Solution, UVP, Core User stories
2. Write **Design Document** - User Stories and flows, Information Architecture, Detailed UX components on each pages 
3. Write **Architecture Document** - Project folder heirachy, Database schema
3. Write **PRD** for each features 
4. Write **Tasks list** for each features
4-1. Prioritize frontend jobs than backend jobs to make final output be more visually predictable. 
5. Develop each task based on **dev-guidelines**
